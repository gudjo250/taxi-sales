# タクシー売上管理（iPhone用Webアプリ）

## 機能
- 日付ごとに最終売上を1回入力
- 毎月16日〜翌月15日締めで総売上、出勤日数、出勤日平均を自動集計
- 休みの記録
- 月移動、過去月の確認
- CSV書き出し、JSONバックアップ
- 広告なし、外部送信なし（端末内保存）

## iPhoneのホーム画面に追加する方法
1. このフォルダ一式をHTTPS対応の静的ホスティング（例：GitHub Pages等）にアップロードします。
2. 公開されたURLをiPhoneのSafariで開きます。
3. 共有ボタン →「ホーム画面に追加」→「追加」を選びます。

## 注意
- このZIPだけでは公開URLは作成されません。ホーム画面に追加するにはHTTPSで公開する必要があります。
- 売上データはブラウザ内（localStorage）に保存されます。Safariの履歴・Webサイトデータを消すと消える可能性があるため、定期的に「データをバックアップ」を使ってください。
- iPhoneのSafariで同じURLを使い続けてください。別ブラウザ・別端末とは自動同期しません。
- 金額は円単位の整数で入力してください。0円は記録削除扱いです。
